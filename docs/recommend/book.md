# 书单推荐

## 总览

| 书名 | 作者 | 一句话 |
| --- | --- | --- |
| **《思考，快与慢》** | 丹尼尔・卡尼曼 | 看清人固有的认知偏差，避开自己做判断时的坑 |
| **《原则》** | 瑞・达利欧 | 搭建一套成体系的决策和做事方式 |
| **《创新者的窘境》** | 克莱顿・克里斯坦森 | 看懂企业为什么会崛起又倒下，理解技术变革怎么改变行业 |
| **《卓有成效的管理者》** | 彼得・德鲁克 | 不管是不是管理者，职场人都能学到怎么把事做好 |

> 推荐阅读顺序：先读《卓有成效的管理者》（薄、好上手），再读《思考，快与慢》和《原则》，最后读《创新者的窘境》（偏商业案例）。

## 一、 《思考，快与慢》（Thinking, Fast and Slow）

| 项目 | 信息 |
| --- | --- |
| **作者** | 丹尼尔・卡尼曼（Daniel Kahneman），心理学家，2002 年诺贝尔经济学奖得主，行为经济学奠基人之一（2024 年去世） |
| **出版** | 英文原版 2011 年；中文版由中信出版社出版 |
| **难度** | 中等，案例多，但篇幅较长 |

### 核心观点

人脑有两套思考方式：

| | 系统 1（快思考） | 系统 2（慢思考） |
| --- | --- | --- |
| **特点** | 自动、快速、凭直觉、不费力 | 刻意、缓慢、讲逻辑、费力 |
| **例子** | 看到一张生气的脸、算 2 + 2 | 算 17 × 24、填一张复杂的表 |
| **问题** | 容易走捷径，产生偏差 | 偷懒，经常直接采纳系统 1 的结论 |

大多数判断失误，都是系统 1 走了捷径、系统 2 又没去检查。

### 书里提到的常见偏差

| 偏差 | 意思 | 生活中的例子 |
| --- | --- | --- |
| **锚定效应** | 先看到的数字会影响后面的判断 | 商品先标高价再打折，显得很划算 |
| **可得性启发** | 越容易想起来的事，越觉得常见 | 看了空难新闻，就觉得坐飞机比开车危险 |
| **损失厌恶** | 损失带来的痛苦大于同等收益带来的快乐 | 股票被套不愿卖，“等回本再说” |
| **框架效应** | 同一件事换个说法，选择就变了 | “存活率 90%” 比 “死亡率 10%” 更让人接受 |
| **规划谬误** | 总是低估完成任务需要的时间和成本 | 项目排期永远不够用 |
| **峰终定律** | 对一段经历的记忆，主要取决于高峰和结尾 | 旅行中途很累，但结尾愉快，回忆起来就是好的 |

### 适合谁

想提高判断质量的人：做投资、做产品决策、做招聘面试，或者只是想少踩坑。

## 二、 《原则》（Principles: Life and Work）

| 项目 | 信息 |
| --- | --- |
| **作者** | 瑞・达利欧（Ray Dalio），桥水基金（Bridgewater Associates）创始人，桥水是全球规模最大的对冲基金之一 |
| **出版** | 英文原版 2017 年；中文版由中信出版社出版 |
| **难度** | 低到中等，像一本条目清单，可以挑着读 |

### 全书结构

| 部分 | 内容 |
| --- | --- |
| **第一部分：我的经历** | 达利欧的个人经历，包括 1982 年误判经济走势、几乎破产的教训 |
| **第二部分：生活原则** | 个人如何做决策、面对现实、从错误中成长 |
| **第三部分：工作原则** | 如何搭建团队和组织，桥水内部的管理方法 |

### 核心观点

- **极度求真、极度透明**：直面现实，不回避问题，鼓励说真话。
- **痛苦 + 反思 = 进步**：犯错和痛苦是成长的信号，关键是事后复盘。
- **五步流程**：
  1. 明确目标
  2. 找出阻碍目标的问题
  3. 诊断问题的根源
  4. 制定解决方案
  5. 执行方案
- **创意择优**：好的想法胜出，而不是职位高的人说了算；决策时按每个人在该领域的“可信度”加权。
- **把原则写下来**：遇到同类问题时，按原则处理，而不是每次凭感觉。

### 适合谁

想给自己建立一套决策框架的人，或者在带团队、想改进团队协作方式的人。

> 作者后来还出了《原则：应对变化中的世界秩序》，讲国家兴衰和经济周期，和本书是两本不同的书。

## 三、 《创新者的窘境》（The Innovator's Dilemma）

| 项目 | 信息 |
| --- | --- |
| **作者** | 克莱顿・克里斯坦森（Clayton Christensen），哈佛商学院教授，“颠覆式创新”理论的提出者（2020 年去世） |
| **出版** | 英文原版 1997 年；中文版由中信出版社等出版 |
| **难度** | 中等，案例偏行业和技术，硬盘行业的数据比较多 |

### 核心问题

**为什么管理得很好的大公司，反而会被新技术打败？**

作者的答案：不是因为大公司犯了错，恰恰是因为它们做了“正确”的事——倾听大客户、投资利润高的业务、追求更好的产品。

### 两种创新

| | 延续性创新 | 颠覆式创新（破坏性创新） |
| --- | --- | --- |
| **方向** | 把现有产品做得更好 | 一开始更差、更便宜、更简单 |
| **客户** | 现有的主流客户 | 被忽视的低端客户或全新市场 |
| **谁擅长** | 大公司（在位者） | 新进入者 |
| **例子** | 硬盘容量越做越大 | 小尺寸硬盘起初容量小，但后来取代了大尺寸硬盘 |

### 大公司为什么会陷入窘境

- **客户决定资源分配**：大客户暂时不需要新技术，公司就不会投入。
- **小市场满足不了大公司的增长需求**：新市场刚开始很小，对大公司来说“不值得做”。
- **新市场无法提前分析**：没有数据，按传统方式做调研和规划行不通。
- **技术进步快于需求**：老产品性能“过剩”，便宜的新产品“够用”后就会抢走市场。

### 对策

成立独立的小团队或子公司去做颠覆式创新，让它的规模和盈利预期匹配小市场，不受主业的考核方式约束。

### 适合谁

想理解行业变迁的人：做技术、做产品、做投资，或者在思考“新技术会不会颠覆我所在行业”的人。

> 作者后来还写了续作《创新者的解答》，重点讲公司怎么主动做颠覆式创新。

## 四、 《卓有成效的管理者》（The Effective Executive）

| 项目 | 信息 |
| --- | --- |
| **作者** | 彼得・德鲁克（Peter Drucker），被称为“现代管理学之父”（1909–2005） |
| **出版** | 英文原版 1967 年；中文版由机械工业出版社出版 |
| **难度** | 低，篇幅不长，适合入门 |

### 核心观点

- **每个知识工作者都是“管理者”**：只要你的工作会影响组织的成果，你就要对自己的有效性负责，和有没有下属无关。
- **有效性是可以学会的**：它不是天赋，而是一系列可以练习的习惯。

### 五个习惯

| 习惯 | 做法 |
| --- | --- |
| **1. 管理时间** | 记录时间花在哪里，砍掉没用的事，把零碎时间整合成大块时间 |
| **2. 重视贡献** | 不只问“我在做什么”，而是问“我能为组织贡献什么成果” |
| **3. 发挥长处** | 用人看长处，而不是盯着短处；对自己也一样 |
| **4. 要事优先** | 一次只做一件最重要的事，敢于放弃过时的任务 |
| **5. 有效决策** | 决策重在正确定义问题，听取不同意见，而不是追求速度 |

### 适合谁

所有职场人，特别是刚开始独立负责项目、觉得“每天很忙但没成果”的人。
