## 一、 江门

### 上川岛（都斛海鲜街）

| 项目 | 信息 |
| --- | --- |
| **位置** | 江门台山市，南海上的海岛 |
| **怎么去** | 开车到台山**山咀港**，坐船约 30–40 分钟到岛上三洲港，再转车到飞沙滩一带 |
| **玩什么** | 飞沙滩、王府洲等沙滩，玩水、看海 |
| **都斛海鲜街** | 在台山**都斛镇**，离山咀港约 40 公里，开车半小时左右；可以买海鲜找店加工 |

> 上岛靠船，节假日船票紧张，建议提前买好往返船票；遇台风会停航。

## 二、 广州

### 1. 森林海

| 项目 | 信息 |
| --- | --- |
| **位置** | **增城区**派潭镇白水寨大道 101 号，紧邻白水寨景区（注意：在增城，不在从化） |
| **类型** | 温泉度假区 + 酒店 |
| **特色** | 嬉水乐园（冬季温泉、夏季矿泉）、森林乐园（萌宠、亲子项目）、房车营地 |
| **住宿** | 温泉度假酒店 427 间客房，都带室内温泉池 |
| **适合** | 带娃、家庭出游 |

### 2. 卓思道温泉度假酒店

| 项目 | 信息 |
| --- | --- |
| **位置** | 从化区良口镇御泉大道 288 号，流溪温泉度假区内，距广州市区约 80 公里 |
| **类型** | 温泉度假酒店 |
| **特色** | 徽派 + 岭南建筑风格；氡温泉，32 个药池；无边际泳池、儿童水上乐园 |
| **住宿** | 合院、山地别墅等，多数客房带露天私汤 |
| **适合** | 情侣、家庭小聚 |

### 3. 从都国际庄园

> 原文写的是“从化国际庄园”，应该是指位于从化的**从都国际庄园**（Imperial Springs）。

| 项目 | 信息 |
| --- | --- |
| **位置** | 从化区良口镇从都大道 1 号，凤凰山脚、流溪河畔；距白云机场约 40 分钟车程 |
| **类型** | 高端度假庄园 |
| **特色** | 占地近 280 万平方米，盛唐风格建筑；有温泉和国际会议中心，常年举办“从都国际论坛”，接待过 200 多位外国前政要 |
| **住宿** | 套房 + 别墅，整体消费偏高 |
| **适合** | 追求私密、安静的高端度假 |

## 三、 河源

两家酒店都在**春沐源小镇**里（源城区埔前镇春沐源大道），小镇背靠大桂山自然保护区，有中心湖、龙骨乐园（亲水儿童乐园）、观光船、皮划艇等，适合亲子。小镇里还有蓝葡萄等其他酒店。

### 1. 春沐源小镇 · 棕榈树酒店

| 项目 | 信息 |
| --- | --- |
| **位置** | 春沐源小镇商业街 2 号楼 |
| **风格** | 欧式 + 地中海风格，临水而建 |
| **住宿** | 七十余间客房，每间都有独立观景阳台 |
| **特色** | 位于商业街，吃饭方便（“第一食堂”口碑较好） |

### 2. 春沐 · 禾悦庄温泉酒店

| 项目 | 信息 |
| --- | --- |
| **位置** | 春沐源大道 1 号 |
| **风格** | 新岭南建筑风格，融合客家、广府、潮汕建筑和岭南园林 |
| **特色** | 温泉酒店，环境清幽，偏中式 |

> 两家怎么选：想住得热闹、吃饭方便选**棕榈树**；想泡温泉、偏好中式园林选**禾悦庄**。

## 四、 惠州

### 1. 中海汤泉

| 项目 | 信息 |
| --- | --- |
| **位置** | 惠城区惠州大道汤泉段 298 号（小金口），惠州市区西北郊 |
| **类型** | 温泉度假村 + 酒店 |
| **特色** | 号称“千年东坡泉，岭南第一汤”（苏轼曾写诗称赞）；碳酸钠钾型高温泉，出水约 70℃；中式园林，飞泉流瀑 |
| **适合** | 离市区近，适合短途泡汤 |

### 2. 碧桂园润扬溪谷温泉酒店

| 项目 | 信息 |
| --- | --- |
| **位置** | 惠阳区 356 省道旁 |
| **类型** | 温泉酒店 |
| **特色** | 偏硅酸温泉，117 个泡池；有水杉湿地，山林溪谷环境 |
| **住宿** | 客房和别墅都带入室温泉池 |

### 3. 十字水生态度假村

| 项目 | 信息 |
| --- | --- |
| **位置** | 龙门县南昆山国家森林公园内 |
| **类型** | 森林温泉度假村 |
| **特色** | 依山临溪而建，藏在竹林里；峭壁温泉、森林无边泳池；建筑用客家夯土墙 + 竹子工艺，拿过多个设计奖 |
| **适合** | 想避暑、亲近自然、安静休息 |

> 南昆山山路较多，开车注意安全；山里比市区凉快，夏天也合适。

## 五、 清远

### 1. 芊丽酒店（现清远新世界酒店）

> 原“清远芊丽酒店”，2023 年更名为**清远新世界酒店**，订房时搜新名字。

| 项目 | 信息 |
| --- | --- |
| **位置** | 清新区三坑镇新丽路 1 号 |
| **类型** | 日式温泉度假酒店（2020 年开业） |
| **特色** | 日本 KKS 设计，日式和风建筑；弱碱性温泉；约 3000 平方米儿童俱乐部，室内外娱乐项目多 |
| **住宿** | 217 间客房，每间带露台，部分房型带露台温泉泡池 |
| **注意** | 有住客反馈公共温泉区和泳池偏小，旺季人多 |
| **周边** | 古龙峡、黄腾峡等景区 |

### 2. 熹乐谷温泉度假区

| 项目 | 信息 |
| --- | --- |
| **位置** | 佛冈县汤塘镇熹谷路 28 号，京珠高速汤塘出口附近 |
| **类型** | 温泉度假区 + 酒店 |
| **特色** | 凤凰温泉：87℃ 氡温泉，9 大温泉区共 60 多个汤池，半山坡布局；唐风建筑 |
| **晚上** | “不夜山谷”夜游 + 庙会美食街 / 自助晚餐 |
| **亲子** | 星球无动力乐园 |
| **住宿** | 套房、汤屋、别墅等，部分房型带独立温泉池 |
